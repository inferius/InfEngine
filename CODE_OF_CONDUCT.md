# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct.

The full text is available at the link above.

## Reporting

Please report unacceptable behavior to **michalosoft@gmail.com**. All reports will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and security of reporters.
